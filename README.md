# Gelee Brawl

Ein 3D-Ragdoll-Physik-Party-Brawler im Stil von Gang Beasts – optimiert für **iPad (Touch & Gamepad)**, **Desktop (Maus & Tastatur)** und **Online-Multiplayer**.

## Features
- **Echte 3D-Ragdoll-Physik** (`cannon-es` + `Three.js`) mit aktivem Gleichgewichts-System, Greifen (`LockConstraint`), Heben, Kopfnüssen und K.O.-System.
- **10 klassische Arenen** inkl. bewegendem Karussell, angreifenden Haien, fahrenden Trucks, Fleischwolf-Walzen, Eisberg und greifbaren Objekten (Kisten, Fässer, Metallplatten).
- **Prozedurale HD-PBR-Texturen** (Glanz-Gelee, Riffelblech, Holzplanken, Eis, Warnstreifen) ohne externe Ladefehler.
- **Charakter-Studio** mit 12 Farben, Hüten (Krone, Zylinder, Wikinger, Bauarbeiter, Stirnband) und Outfits.
- **Universal-Steuerung**: Virtueller Dual-Touch-Stick für iPad, WASD + Maus, sowie Bluetooth-Controller (PS5 DualSense / Xbox).
